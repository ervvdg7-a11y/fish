TropicalFishBreed — исходники плагина

Функция:
- ПКМ по тропической рыбке с ламинарией (kelp), когда рядом есть другая тропическая рыбка.
- Появляются сердечки и через 2 секунды создаётся новая рыбка.
- На пару действует 5-минутная задержка.

ВАЖНО:
- Это исходный проект, не готовый JAR.
- pom.xml сейчас указывает Paper API 1.21.4 и Java 21 как базу для сборки.
- Это не подтверждает совместимость с сервером Minecraft/Paper 26.3. Для точной сборки нужно заменить версию paper-api и api-version на те, которые доступны для вашей версии сервера.
- Стандартный Bukkit/Paper API может не поддерживать настоящий маленький визуальный вариант тропической рыбки; setBaby() зависит от API/типа сущности и может потребовать адаптации под целевую версию.
- Сборка: mvn package; JAR будет в target/TropicalFishBreed-1.0.0.jar
